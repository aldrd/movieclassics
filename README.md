# MovieClassics

Генератор «таблицы киноклассики»: самые популярные фильмы и сериалы по числу
голосов на IMDb за каждый год, с постерами и описаниями (рус/англ) из TMDB.

## Правила

- **Фильмы**: по 50 самых голосованных за каждый год, начиная с 1937.
- **Сериалы**: по 20 самых голосованных за каждый год, начиная с 1980.
- Текущий год — пропорционально прошедшей доле года (полгода = половина квоты).
- Упорядочено по годам, внутри года — по числу голосов.

## Запуск (раз в месяц)

```
dotnet run
```

- IMDb: официальные датасеты `title.basics` + `title.ratings` (datasets.imdbws.com),
  скачиваются при устаревании кэша (>20 дней).
- TMDB: `find` по IMDb id + детали `language=ru-RU`; результаты кэшируются в
  `cache/tmdb-cache.json`, поэтому повторные прогоны обогащают только новые титлы.
- Результат: `docs/data/movies.json`, `docs/data/series.json`, `docs/data/meta.json`
  и страница `docs/index.html` — публикуется на GitHub Pages.

## Данные (для приложения)

Каждая запись: `imdbId`, `tmdbId`, `kind` (фильм/сериал), `year`, `rating`,
`votes`, `titleOriginal`, `titleEn`, `titleRu`, `overviewEn`, `overviewRu`,
`poster` (w500), `posterSmall` (w185).

`--smoke` — короткий прогон по последним трём годам для проверки.
